# 01: Descubrir una primera camiseta

**What to build:** Descubrir una primera camiseta como una entrega funcional del recorrido Jerskits, con diseño responsive y pruebas desde el navegador del comportamiento añadido.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] La aplicación se ejecuta con React, TypeScript y Vite, con rutas de inicio, catálogo inicial y detalle.
- [x] El invitado navega desde el inicio hasta una camiseta con imágenes, información y precio en USD.
- [x] Las vistas móvil y escritorio siguen la captura; la navegación funciona con teclado.
- [x] La base de internacionalización muestra inglés inicialmente y permite ampliar las traducciones sin rehacer las páginas.
- [x] Una prueba desde el navegador verifica el recorrido de descubrimiento.
