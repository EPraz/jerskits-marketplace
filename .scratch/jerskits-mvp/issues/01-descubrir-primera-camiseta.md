# 01: Descubrir una primera camiseta

**What to build:** Descubrir una primera camiseta como una entrega funcional del recorrido Jerskits, con diseño responsive y pruebas desde el navegador del comportamiento añadido.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] La aplicación se ejecuta con React, TypeScript y Vite, con rutas de inicio, catálogo inicial y detalle.
- [ ] El invitado navega desde el inicio hasta una camiseta con imágenes, información y precio en USD.
- [ ] Las vistas móvil y escritorio siguen la captura; la navegación funciona con teclado.
- [ ] La base de internacionalización muestra inglés inicialmente y permite ampliar las traducciones sin rehacer las páginas.
- [ ] Una prueba desde el navegador verifica el recorrido de descubrimiento.
