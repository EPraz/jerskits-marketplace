# 04: Completar una compra simulada

**What to build:** Completar una compra simulada como una entrega funcional del recorrido Jerskits, con diseño responsive y pruebas desde el navegador del comportamiento añadido.

**Blocked by:** 03: Seleccionar variantes y gestionar el carrito.

**Status:** ready-for-agent

- [ ] El checkout presenta el resumen y permite comprar como invitado sin tarjeta.
- [ ] Nombre completo, email, país, ciudad y dirección son obligatorios; teléfono y código postal son opcionales.
- [ ] Se rechazan vacíos, solo espacios y email inválido con errores junto al campo.
- [ ] El botón de datos de ejemplo completa un formulario válido.
- [ ] Confirmar muestra referencia y artículos del pedido simulado y vacía el carrito.
- [ ] Los datos de envío no se guardan permanentemente.
- [ ] Las pruebas de navegador verifican errores, ejemplo y confirmación con artículos y totales.
